# Проверка безопасности

Полный `npm audit` после обновления зависимостей 6 ноября 2026 года:
0 уязвимостей. Исходный результат: 105 (38 critical, 42 high, 23 moderate,
2 low). Это результат проверки известных npm advisories на момент запуска,
а не гарантия отсутствия ошибок в приложении или операционной системе.

Все npm-зависимости, включая браузерные библиотеки, исторически размещены
в `devDependencies`. Поэтому `npm audit --omit=dev` здесь не является полезной
проверкой: запускай полный аудит.

```sh
npm ci
npm audit
npm test
npm run build
```

Сборка использует Webpack 5 и его `importModule` вместо устаревшего
`extract-loader` с Babel 6. Браузерные DOMPurify и anchorme обновлены;
созданные ссылки повторно проходят HTML-санитизацию. Диагностический вывод
аргументов подключения, включавших пароль, удалён.

`protobufjs` обновлён с 5 до 8 через override. Патч
`patches/mumble-streams+0.0.4.patch` адаптирует Mumble к новому API, сохраняя
имена полей, отсутствие необязательных полей, пустые списки и Long timestamp.
Эти свойства и формат пакетов проверяются в `test/protocol.test.cjs`.
Override `ws` обновляет старую транзитивную зависимость WebSocket.
Оба патча применяются автоматически через `postinstall`; не отключай скрипты
установки в рабочей сборке.

В итоговом Docker-образе нет Node.js, npm и инструментов сборки. Websockify
работает от непривилегированного пользователя и соединяется с одним сервером,
заданным через `MUMBLE_SERVER`. Compose отключает capabilities и запись
в корневую файловую систему, ограничивает память, CPU и число процессов.
Публичная конфигурация генерируется в `/run/mumble-web` в tmpfs и доступна
через ссылку из каталога статических файлов. Пароли туда не записываются.

Системные пакеты Debian и Python/websockify не проверяются `npm audit`.
Для них обновляй базовые образы и пересобирай образ с `--pull --no-cache`;
перед публикацией также проверяй итоговый образ сканером уязвимостей.
Сохраняй HTTPS на Caddy и пароль/ACL на самом Mumble-сервере: веб-клиент
не добавляет отдельную серверную авторизацию или защиту от DDoS.
